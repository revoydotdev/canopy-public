# ADR-902: A record whose fix is an operator decision

**Status:** Accepted
**Date:** 2026-08-07

## Context

Synthetic fixture for the not_applicable classification.

## Decision

This is a reasoned non-goal. Branch protection requires a platform plan this
repository does not have, so no code change by an agent working inside the
repository can satisfy it; it is an operator/business decision.

## Consequences

Recorded so a future reader does not mistake the gap for an oversight.

## Test implications

None directly - this ADR does not introduce a mechanism.
