# ADR-904: A record whose real fix is an operator/business decision

**Status:** Accepted
**Date:** 2026-08-07

## Context

Synthetic fixture for the not_applicable classification whose disclaimer is
that the remedy lies outside the repository.

## Decision

Branch protection requires a paid platform plan, so this is an
operator/business decision and not something an agent working inside the repo
can decide.

## Consequences

Recorded so a future reader does not mistake the gap for an oversight.

## Test implications

None directly - this is an operator/business decision, not a code change.
