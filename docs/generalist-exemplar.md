# Cross-language generalist exemplar

`bun run demo:generalist` is a recorder for three fresh, provider-backed Revoy2 campaigns in standalone TypeScript, Python, and Go repositories. A sealed lane begins with a failing language-native test suite, runs at the governed tier through the Claude Code integration, applies only the verified campaign result, and reruns the acceptance suite independently.

The generator samples the live tmux pane once per second and renders those samples on their original clock. Publication fails if a campaign cannot be attributed, adoption or acceptance fails, media is absent, privacy scanning finds account or credential material, or package checksums do not verify.

`--resume` retains any lane whose campaign, adoption, independent acceptance, and WebM are already complete, while rebuilding only failed or incomplete lanes. Live CLI progress is emitted on stderr with `--progress`, leaving stdout as one parseable JSON result. A critic-blocked retry receives an explicit corrective directive derived from its bounded retry capsule rather than repeating the original prompt unchanged.

Default output is under `/mnt/sda2/revoy2/exemplars/generalist/`. The resulting `index.html` is a responsive three-lane evidence gallery; each lane also includes its raw capture timeline, initial and final acceptance logs, campaign receipt, and real-time WebM.

A sealed exemplar supplies fixture-specific evidence of breadth and governed completion. It does not establish model superiority over an uncontrolled baseline or broad provider parity, and it reports provider identity only at the integration level.
